# A股三大指数 · 逐年低点/高点区间报表（每日自动更新）

自动抓取 **上证指数 / 创业板指 / 科创50** 的日K线，计算逐年「低点区间 / 高点区间」
（±5% 容忍带主区间法），并在顶部给出「当前位置实时读数」——判断今日收盘处于
年内低点带 / 高点带 / 中间区，作为低买高卖的前瞻参考。

## 数据源
- 东方财富行情接口（日K线，前复权）
- 报告口径：**事后复盘**；「当前位置实时读数」为**前瞻代理**（以年初至今最低/最高
  收盘为锚，沿用 ±5% 容忍带），不构成投资建议。

## 每日自动更新
- GitHub Actions：`schedule` 于**北京时间每交易日 17:30** 自动重跑（收盘后数据就绪）。
- 触发后重新抓取 → 重算 → 重新生成 `index_low_high_report.html` 并推送。
- 仓库已启用 **GitHub Pages**，访问：
  `https://<owner>.github.io/<repo>/index.html`（或根路径 `index.html`）。

## 本地运行
```bash
python fetch_compute.py     # 抓取三指数日K线 + 计算区间 + 当前位置
python fetch_etf.py         # 抓取代表 ETF 日K线
python build_outputs.py     # 生成 index_low_high_report.html / .xlsx
```

## 区间定义
1. 年度最低点 = 全年每日最低价最小值；年度最高点 = 全年每日最高价最大值。
2. 低点区间 = 以「年最低点交易日」为锚向两侧扩展，直到收盘价首次突破
   年最低 ×(1+5%) 的连续时段；高点区间对称（阈值 年最高 ×0.95）。仅取主区间。
